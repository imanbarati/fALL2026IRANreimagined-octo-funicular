# Security and contributor safety

This project concerns a country where writing, sharing or publishing can be dangerous. Treat contributor safety as a core requirement.

- Do not publish real names, addresses, phone numbers, photos or testimonies of people inside Iran without explicit, informed consent and a safety review.
- Do not commit private testimony archives. Keep them encrypted, off GitHub, with offline backups.
- Contributors may use pseudonymous GitHub accounts and the GitHub no-reply email (`ID+username@users.noreply.github.com`). Enable "Keep my email addresses private" and "Block command line pushes that expose my email".
- Strip metadata (EXIF, document properties) from images and files before committing.
- Report vulnerabilities or safety concerns through GitHub private vulnerability reporting (Settings > Security > Private vulnerability reporting).
- Never commit tokens, passwords or API keys. Secret scanning and push protection should be enabled.
